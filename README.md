# 行銷管理課程前測問卷（互動式網頁版）

教學實踐研究計畫「在 GenAI 時代培養行銷教育中的認識論否決能力」之基線調查。
主持人：世新大學企業管理學系　林建江 助理教授。

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 互動式網頁問卷，單檔、無建置流程，採 Apple Human Interface Guidelines 設計語言 |
| `GoogleForm.gs` | 原始的 Google 表單自動生成腳本（題庫來源） |

## 題目結構

- 知情同意（同意開關，未開啟無法開始）
- 第一部分　基本背景資料：A 個人資料、B 學業自評、C 課程修習、D GenAI 使用經驗（共 9 題）
- 第二部分　量表題項：九個構面共 46 題，五點李克特量表，每頁一個構面
- 附加題　情境判斷 SJ1（選填）
- 檢查頁：逐段顯示完成度，可直接跳回補答

## 可調整參數

`index.html` 內 `<script>` 開頭的設定區塊，對應 Google Apps Script 版本的同名變數：

- `CONTACT_EMAIL` — 發放前務必填入真實聯絡信箱
- `SHOW_ITEM_CODES` — 是否在題目前顯示 IM1／TD1 等題號代碼（預設關閉，避免作答提示效應）
- `SHOW_CONSTRUCT_NAMES` — 是否顯示「內在動機」等構面名稱（預設關閉，理由同上）

## 作答資料

- 作答過程即時寫入瀏覽器 `localStorage`，關閉頁面後可接續填答。
- 送出時寫入 Artifact 資料庫的 `responses` 集合，一位填答者一筆文件，內容包含背景資料、逐題原始分數、各構面加總與平均、情境題文字、填答秒數。
- 不蒐集姓名、學號與電子郵件。
- 完成頁可下載個人填答備份（CSV，UTF-8 BOM，Excel 可直接開啟）。

## 直接開啟

`index.html` 可單獨以瀏覽器開啟預覽；此時沒有資料庫可寫入，送出僅會保存在本機並提示以備份方式留存。
